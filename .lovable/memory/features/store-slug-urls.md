---
name: Store Slug URLs
description: Stores use unique slug field for pretty share URLs (/store/jayees-gadgets)
type: feature
---
- `stores.slug` is unique, auto-generated by `stores_set_slug` trigger from `name` on insert and on name change.
- `slugify()` function lowercases and hyphenates; collisions get `-1`, `-2`, ...
- Route `/store/:slug` accepts either slug or UUID. UUID lookups redirect to the slug URL.
- og-redirect edge function accepts either slug or UUID for `id` param when `type=store`.
- All internal `<Link to={`/store/${store.slug || store.id}`}>`.
